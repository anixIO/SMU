# Контроль усталости

Приложение оценивает признаки усталости по изображению с веб-камеры: длительное закрытие глаз, зевоту, долю времени с закрытыми глазами (PERCLOS), наклон и поворот головы. Показывает показатели в браузере, произносит предупреждения и сохраняет метрики сеанса в CSV.

Кадры обрабатываются локально через MediaPipe и OpenCV и не сохраняются. Приложение использует настраиваемые пороги и не является средством медицинской диагностики. Точность зависит от освещения, положения камеры и видимости лица.

## Запуск

Рекомендуется Python 3.11. Нужны веб-камера и браузер с доступом к камере.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python web.py
```

В Windows окружение активируется командой `.venv\Scripts\activate`.

Откройте <http://127.0.0.1:8000>, нажмите «Начать наблюдение» и разрешите доступ к камере. Кнопка «Проверить голос» воспроизводит предупреждение. Для русской речи нужен доступный русский голос браузера или операционной системы; если синтез речи недоступен, используется звуковой сигнал.

«Завершить» освобождает камеру и закрывает отчёт. Файлы CSV и журналы записываются в `output/`, который исключён из Git. График PERCLOS и список предупреждений находятся в раскрываемой истории сеанса.

Оконная версия OpenCV запускается отдельно:

```bash
python main.py
```

Выход из оконной версии — Esc. На macOS она произносит предупреждения системной командой `say`; на других платформах использует звуковой сигнал.

## Настройки

Пороги находятся в `config.yaml`. Изменения применяются при новом запуске наблюдения.

| Параметр | Назначение |
| --- | --- |
| `EYE_AR_THRESH`, `EYE_CLOSED_SECONDS` | Порог EAR и длительность закрытия глаз |
| `MAR_THRESH`, `YAWN_SECONDS` | Порог MAR и длительность открытия рта |
| `PERCLOS_WINDOW_SECONDS`, `PERCLOS_MIN_SECONDS` | Скользящее окно и время накопления данных |
| `PERCLOS_THRESH` | Предельная доля времени с закрытыми глазами |
| `HEAD_PITCH_THRESH` | Допустимый наклон вперёд/назад относительно камеры, в градусах |
| `HEAD_YAW_THRESH` | Допустимый поворот влево/вправо, в градусах |
| `ALERT_COOLDOWN` | Минимальный интервал между предупреждениями |
| `CAMERA_INDEX` | Номер камеры для оконной версии |

Углы оцениваются по шести точкам [канонической модели лица MediaPipe](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/modules/face_geometry/data/canonical_face_model.obj). При потере лица или длительном пропуске кадров временные показатели сбрасываются.

## Проверки

```bash
python -m unittest discover -s tests -v
python web.py check
```

Дополнительная проверка клиентской логики требует Node.js 18+:

```bash
node tests/test_frontend.js
```

Тесты не включают камеру: они проверяют расчёты на искусственных данных, API, выгрузку CSV и логику оповещений. Восприятие голоса и точность распознавания на конкретной камере проверяются отдельно.

## Структура

```text
main.py                Оконная версия
web.py                 Локальный сервер Django и API
config.yaml            Пороговые значения
src/                   Детектор, расчёты, интерфейс OpenCV и отчёты
templates/design.html  Разметка страницы
static/                Стили и клиентская логика
tests/                 Автоматические проверки
```

Веб-версия рассчитана на один локальный сеанс и запускается в одном потоке. Для публичного сервера потребуются отдельные пользовательские сеансы и настройка развёртывания; GitHub Pages не запускает Django.
